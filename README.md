# dev-portfolio

A personal developer portfolio showcasing creative interfaces, projects, technical skills, and my journey in software development.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

The Vite base path is configured for this repository at `/dev-portfolio/`. To publish:

1. Push the repository to GitHub with the default branch named `main`.
2. In **Settings → Pages**, set the source to **GitHub Actions**.
3. Push to `main` or run **Deploy portfolio to GitHub Pages** from the Actions tab.

The workflow builds the site and deploys the generated `dist` directory.
